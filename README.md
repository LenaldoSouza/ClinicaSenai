Clínica SENAI

Sistema de gerenciamento de uma clínica médica, desenvolvido como projeto escolar no SENAI.

Sobre o projeto

O Clínica SENAI é uma aplicação web desenvolvida com o objetivo de facilitar o gerenciamento de informações de uma clínica médica, permitindo organizar e visualizar dados relacionados a consultas, pacientes e exames.

O projeto faz parte de uma atividade acadêmica, tendo como objetivo colocar em prática os conhecimentos adquiridos durante o curso de desenvolvimento de sistemas.

Funcionalidades

Consultas: visualizar e gerenciar consultas médicas.

Pacientes: cadastrar, visualizar e gerenciar pacientes.

Exames: registrar, visualizar e gerenciar exames.

Tecnologias utilizadas

C#

ASP.NET Core MVC

Entity Framework Core

HTML5

CSS3

Bootstrap

SQL Server

Estrutura do projeto

O projeto utiliza o padrão arquitetural MVC (Model-View-Controller), organizando a aplicação em três componentes principais:

Models: representam as entidades e os dados da aplicação.

Views: responsáveis pela interface visual.

Controllers: responsáveis pelo processamento das requisições e comunicação entre Models e Views.

Objetivo acadêmico

Este projeto foi desenvolvido com finalidade educacional, visando praticar conceitos de desenvolvimento web, programação orientada a objetos, integração com banco de dados e utilização do padrão MVC.
